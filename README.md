# 🌶️ 小辣椒 APP - 高级个人定制面板

**您的专属导航中心 · 高效从这里开始**

高端个人导航面板，集成网站管理、本地程序启动、任务管理、提醒系统、云端同步于一体。纯前端单文件设计，开箱即用。

## 📖 使用说明

### 分类管理
1. 点击左侧或右侧顶部的「+」按钮添加分类
2. 输入分类名称和图标（emoji）
3. 选择区域（工作区/休闲区）
4. 拖拽分类卡片可重新排序或跨区移动
5. 鼠标悬停分类显示编辑/删除按钮

### 添加网站/程序/目录
1. 点击分类卡片查看详情
2. 点击右上角「+ 添加网站」按钮
3. 选择类型：🌐网址 / 🖥️程序 / 📁目录
4. 填写信息：
   - **名称** - 如 GitHub
   - **路径/网址** - 完整路径或网址
   - **图标** - emoji 或文字
   - **简介** - 简短描述（可选）
5. 保存后即时显示

### 拖拽添加（快捷方式）
1. 从桌面或资源管理器拖拽文件/快捷方式到详情页
2. 自动识别类型（程序/目录/网址）
3. 自动填充名称和路径
4. 如浏览器无法获取路径，会提示手动输入

**获取路径的方法：**
- 快捷方式：右键 → 属性 → 复制"目标"字段
- 文件/文件夹：右键按住 `Ctrl+Shift+C` 复制路径

### 拖拽排序
- **分类拖拽** - 按住分类卡片拖到目标位置，蓝色预览线指示插入位置
- **网站拖拽** - 详情页内拖拽排序，或拖到其他分类
- **任务拖拽** - 四象限内拖拽或跨象限调整优先级
- **象限拖拽** - 拖拽象限标题栏的 ⠿ 手柄，自定义四象限布局顺序
- **预览线** - 蓝色线显示插入位置（顶部/底部）

### 今日工作
1. 面板中央默认显示今日工作页面
2. 点击右上角「添加任务」或「添加提醒」
3. 选择任务类型（核心/高优/常规/必须完成）
4. 设置截止日期和时间节点
5. 拖拽任务可调整优先级
6. 点击任务复选框标记完成状态（触发粒子特效）

### 全局快速搜索
1. 按 `Ctrl+K` 或 `Ctrl+P` 唤出搜索框
2. 输入关键词实时过滤网站、任务和功能
3. 使用 ↑↓ 键导航，回车打开
4. 按 ESC 或点击外部区域关闭

### 云端同步
1. 点击右上角 ⚙️ 设置按钮
2. 进入「同步」设置页
3. 注册账户或登录已有账户
4. 点击「立即同步」手动同步
5. 可开关自动同步

### 安全锁定
1. 点击右上角 ⚙️ 设置按钮
2. 进入「安全锁定」区域
3. 设置无操作锁定时间（0-120 分钟，0 表示禁用）
4. 点击「改密码」设置 4 位数字密码
5. 点击「锁定」可立即锁定面板
6. 锁定时输入密码解锁

### 语言切换
1. 点击右上角 ⚙️ 设置按钮
2. 在「语言 / Language」区域选择 中文/English
3. 界面即时切换语言

### 数据备份
1. 点击右上角 ⚙️ 设置按钮
2. **导出数据** - 导出所有分类和网站为 JSON
3. **导入数据** - 从 JSON 文件恢复数据
4. **保存今日工作** - 导出为 TXT 文本（工作日报格式）
5. **恢复今日工作** - 从 TXT 或 JSON 恢复任务

## 🆘 常见问题

### 点击程序/文件卡片无反应
1. 检查是否安装了协议处理器（运行 `launcher/install.bat`）
2. 测试协议：按 `Win+R`，输入 `mypanel://notepad.exe`
3. 浏览器可能提示"此网站试图打开 xxx"，选择"允许"
4. 查看调试日志：`%TEMP%\mypanel-debug.txt`

### 中文路径无法打开
1. 确认使用 PowerShell 版本（`launcher.ps1`）
2. 重新运行 `launcher/install.bat` 安装
3. 检查 PowerShell 执行策略：`powershell -Command "Get-ExecutionPolicy"`
4. 如为 `Restricted`，运行：`powershell -Command "Set-ExecutionPolicy RemoteSigned -Scope CurrentUser -Force"`

### 拖拽无法排序
1. 确保从一个卡片拖到另一个卡片（不是空白处）
2. 拖拽时鼠标应变为移动图标（不是禁止标志）
3. 查看浏览器控制台是否有错误（F12）

### 数据丢失
1. localStorage 可能因清除浏览器数据而丢失
2. 定期使用"导出"功能备份数据
3. 导入备份可恢复数据
4. 登录账户后可使用云端同步功能

### 提醒没有通知
1. 检查浏览器通知权限是否已授予
2. 首次点击页面时会自动申请通知权限
3. 即使通知被拒绝，页面内仍会弹窗 + 播放提示音
